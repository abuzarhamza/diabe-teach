## 2026-10-25 — Single Entrypoint (`openapi-backend`), `x-api-key` Gate & 100% Class-Based Architecture (`AppRuntime`, `OpenApiHttpApp`, `BaseHttpHandler`)

- **On 2026-10-25**, [Tickets 05 & 06](../.scratch/get-pack-by-id-endpoint/issues/05-inbound-outbound-naming-and-central-yaml-routing.md) renamed `src/adapters/driving` $\to$ `src/adapters/inbound` and `src/adapters/driven` $\to$ `src/adapters/outbound`, and installed **`openapi-backend`** so [`docs/api/openapi.yaml`](../docs/api/openapi.yaml) is the single YAML routing source of truth.
- **On 2026-10-25**, [Ticket 07](../.scratch/get-pack-by-id-endpoint/issues/07-x-api-key-header-validation-and-openapi-security-handler.md) added the global `ApiKeyAuth` (`x-api-key`) security scheme to [`docs/api/openapi.yaml`](../docs/api/openapi.yaml) and enforced timing-safe validation at the `openapi-backend` gateway (`401 UNAUTHORIZED_TOKEN`).
- **On 2026-10-25**, [Ticket 08](../.scratch/get-pack-by-id-endpoint/issues/08-remove-redundant-per-endpoint-netlify-function-and-duplicate-routing-code.md) removed the redundant `netlify/functions/get-pack-by-id.ts` file and duplicate URL regexes so [`netlify/functions/api.ts`](../netlify/functions/api.ts) is the sole Netlify Function entrypoint.
- **On 2026-10-25**, [Ticket 09](../.scratch/get-pack-by-id-endpoint/issues/09-consolidate-mongodb-outbound-and-move-config-into-src.md) and [Ticket 10](../.scratch/get-pack-by-id-endpoint/issues/10-refactor-procedural-functions-into-cohesive-classes-and-top-level-app-runtime.md) consolidated all MongoDB collection/URI wiring into `src/adapters/outbound/` (`MongoCurriculumPackRepository.fromConfig` + `MongoConnectionManager`), eliminated `netlify/config/` and `src/config/`, placed the Composition Root in a visible top-level [`AppRuntime`](../src/app-runtime.ts) class (`src/app-runtime.ts` + `src/app-runtime.types.ts`), and refactored all Inbound HTTP modules into cohesive classes ([`OpenApiHttpApp`](../src/adapters/inbound/http/create-app.ts), [`BaseHttpHandler`](../src/adapters/inbound/http/endpoint-handler.factory.ts), [`GetPackByIdHttpHandler`](../src/adapters/inbound/http/get-pack-by-id.handler.ts)).
