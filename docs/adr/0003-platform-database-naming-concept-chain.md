# Platform Database Naming Convention: `concept_chain`

We adopt **`concept_chain`** (and environment-qualified variants like `concept_chain_dev`, `concept_chain_staging`, `concept_chain_prod`) as the canonical database name across all persistence adapters. While the repository originates from the *Diabe-teach* randomized controlled trial, the underlying data store houses aggregates for the entire subject-agnostic **Concept-Chain Educational Game Engine**—including multi-subject `CurriculumPack` catalogs and multi-cohort `GameSession` records. Naming the database `concept_chain` rather than `diabe_teach` aligns the persistence layer with our domain boundary (ADR-0001, ADR-0002, and `GLOSSARY.md`), preventing legacy coupling as new discipline packs and sessions are introduced.
