# Subject-Agnostic Engine with Pluggable Curriculum Packs

Although this repository originates from the *Diabe-teach* randomized controlled trial on undergraduate diabetes mellitus education (`papers/diabe-teach.pdf`), we decided to make the game engine, board topology validator, scoring engine, session state machine, and API endpoints completely subject-agnostic, isolating all domain-specific content inside pluggable **Curriculum Packs** (`CurriculumPack`). This allows educators or game creators to spin up new concept-chaining games for any discipline (such as Cardiology, Pharmacology, or Constitutional Law) with customizable board dimensions, chain length rules, AI adjudicator personas, and optional study assessments without modifying engine or API code, while shipping `diabe-teach` as the canonical built-in pack.
