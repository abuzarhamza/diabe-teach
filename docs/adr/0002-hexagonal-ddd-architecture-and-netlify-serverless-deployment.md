# Hexagonal DDD Architecture, MongoDB Persistence, and Netlify Serverless API Deployment

We structure the backend and API using **Domain-Driven Design (DDD)** inside a strict **100% class-based Hexagonal Architecture (Ports & Adapters)** (`src/domain/`, `src/application/`, `src/adapters/inbound/`, `src/adapters/outbound/`, and top-level `src/app-runtime.ts`), centrally routed by **`OpenApiHttpApp`** (`openapi-backend` reading `docs/api/openapi.yaml`) and deployed on **Netlify Functions v2** (running on AWS Lambda) via a **single entrypoint** (`netlify/functions/api.ts` wired through `AppRuntime.createServerlessHttpHandler()` and `AppRuntime.defineServerlessRouteConfig()`) and backed by **MongoDB** (`MongoCurriculumPackRepository`, `MongoSessionRepository`, and `MongoConnectionManager` inside `src/adapters/outbound/` with a warm-cached serverless `MongoClient` and document `version` optimistic concurrency control). The inner **Domain Ring** models `GameSession` and `CurriculumPack` as transactional Aggregate Root classes alongside pure, zero-I/O Domain Service classes (`BoardTopologyService`, `CurriculumPackValidatorService`, `RoundScoringService`, `MetacognitiveAnalyticsService`), while the **Application Ring** orchestrates use cases exclusively through Inbound Ports (`*.port.ts`) and Outbound Ports (`SessionRepositoryPort`, `CurriculumPackRepositoryPort`, `CapabilityTokenPort`, `NarrativeAdjudicatorPort`, `SessionEventPublisherPort`, `ClockPort`, `IdGeneratorPort`), with all interface/type/DTO contracts (`*.types.ts`, `*.port.ts`, `*.dto.ts`) strictly separated from class implementations across every ring. Each HTTP Inbound Adapter (`src/adapters/inbound/http/`) is a class extending the abstract **`BaseHttpHandler<TQuery, TResult>`** template-method class (`handle(request, context)` calling `transformRequest -> execute -> BaseHttpHandler.jsonResponse / BaseHttpHandler.mapDomainErrorToResponse`), while `OpenApiHttpApp` enforces `x-api-key` validation (`ApiKeyAuth`) and dispatches matched `operationId`s to their endpoint handler classes.
