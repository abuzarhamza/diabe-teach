# 02: Tracer: Teacher login → Game setup → Start game → teacher screen

**What to build:** A teacher opens Teacher login, signs in with name and email (demo sign-in, clearly labelled, no password, remembered in this browser), lands on Game setup, picks a built-in Curriculum Pack, sets chain-building and peer-review minutes (or makes either teacher-paced), and presses **Start game**. That creates the Game Session through the shared mock and opens the teacher screen. The teacher screen shows the new room code, the signed-in teacher, the pack and timings in use, and a "Sign out" link back to Teacher login. Learner timers follow the chosen times. Opening Game setup or the teacher screen while signed out redirects to Teacher login. "Start a new session" on the teacher screen (both buttons, after the existing confirm) goes to Game setup. "Create session" / "Start session" wording becomes "Start game". See `../spec.md` → Solution 1, 2, 4 and user stories 1–9, 19–23, 26–32, 34–35.
