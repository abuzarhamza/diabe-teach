The “Sign in” trace

LoginPage.handleSubmit                         features
  └─ signInCredentialsProblem()               domain   (empty field → stop, nothing sent)
  └─ signIn.mutate()  (useMutation)           features
       └─ signInInstructor()                  api
            └─ apiRequest("POST", …/sign-in)  api      fetch · [API] log · ApiHttpError
            └─ saveAccount()                  api      localStorage + notify listeners
       └─ onSuccess → navigate("/setup")      features
            └─ requireTeacher (loader)        features token ok → continue
            └─ TeacherRoute → useQuery(/me)   features 401 → token cleared → /login + reason
on error: signIn.error → loginErrorView() (domain) → ErrorBanner (features)
