2. Checklist: How to Add Any New Endpoint (100% Class-Based)

  1. Confirm the operationId in docs/api/openapi.yaml (e.g., listCurriculumPacks or createGameSession). Do not create a new file in netlify/functions/.
  2. Define the Inbound Port contract in src/application/ports/<use-case>.port.ts (*Query, *Result, *UseCasePort).
  3. Implement the Use Case class in src/application/use-cases/<use-case>.use-case.ts.
  4. Create the Handler class extending BaseHttpHandler<TQuery, TResult> in src/adapters/inbound/http/<endpoint>.handler.ts, implementing transformRequest(input) and protected execute(query).
  5. Register the handler class on OpenApiHttpApp in src/adapters/inbound/http/create-app.ts inside the OpenAPIBackend handlers map.
