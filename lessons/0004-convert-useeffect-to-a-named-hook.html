What changed in the code (commit 5efbd2c)

You said TanStack Query felt like too much for a first React project. So the screens no longer use it directly. They call hooks named for what they do. Only web/src/features/accounts/account-hooks.ts talks to TanStack. ESLint now refuses a TanStack import anywhere else, except main.tsx and App.tsx. 

// TeacherRoute.tsx — before
const confirmation = useQuery<InstructorAccountView, ApiHttpError>({ queryKey: …, queryFn: …, enabled: …, retry: … });

// TeacherRoute.tsx — now
const confirmation = useCurrentAccount(account);

A custom hook is a function whose name starts with use and that calls other hooks. It hides how behind a name that says what (react.dev, Reusing Logic with Custom Hooks). You wrote custom hooks in Namaste React (useRestaurantMenu). This is the same idea, with useQuery inside instead of useEffect.

The real hooks

Read: useCurrentAccount

export function useCurrentAccount(account: StoredAccount | null) {
  return useQuery<InstructorAccountView, ApiHttpError>({
    queryKey: ["accounts", "me", account?.accountId],   // a new teacher → a fresh answer
    queryFn: getCurrentAccount,                          // from web/src/api/
    enabled: account !== null,                           // ask only while signed in
    retry: (failureCount, error) => error.status !== 401 && failureCount < MAX_RETRIES,
  });
}

Did your right-hand side match? enabled has its own guide: Dependent Queries.

Write: useSignIn

// account-hooks.ts
export function useSignIn({ onSuccess, onError }: SendCallbacks) {
  return useMutation<StoredAccount, ApiHttpError, Credentials>({
    mutationFn: ({ email, password }) => signInInstructor(email, password),
    onSuccess,
    onError,
  });
}

// LoginPage.tsx — the screen decides what happens next
const signIn = useSignIn({
  onSuccess: () => navigate("/setup"),
  onError: error => focusField(loginErrorView(error).focusField),
});
// in handleSubmit:  signIn.mutate(credentials)
// in render:        signIn.isPending · signIn.error

Why pass onSuccess in? Navigation and focus belong to the screen. The hook only knows how to sign in. This mirrors the course's “lifting state up”: the parent decides, the child does.
